NOIR TV is a complete native Kotlin Android home launcher with remote navigation, installed app discovery, favorites, ordering, search, hidden apps, bilingual RTL UI and static/custom wallpapers.

Download Premium-TV-Launcher.apk to install. Premium-TV-Launcher-Complete.zip includes the Android Studio project, official Gradle Wrapper, the same APK and Arabic installation/restore instructions. SHA-256 files accompany both downloads.

Published builds require Android Lint, JVM tests, APK signature verification and four Android 10 emulator tests to pass. Check this release's Actions run for exact evidence. The actual X96Q Pro hardware, vendor HOME policy and performance on 1 GB / 4K devices still require testing.

Minimum Android 6.0 (API 23). Published X96Q Pro specifications typically list Android 10; confirm your actual device version. No root, ads, account, runtime web API or background services.

The optimized APK uses a test signing certificate. For long-term updates, build release with your own stable private signing key. Different CI runs may have different test certificates.

Installation and restore guide: docs/INSTALL-AR.md inside the ZIP. Keep the original launcher installed.
