# NOIR TV — Premium Android TV Launcher

تطبيق Home Launcher أصلي مكتوب بلغة Kotlin، بهوية سوداء هادئة وبطاقات واضحة للريموت.
المشروع تطبيق Android كامل؛ لا يستخدم WebView أو HTML أو إعلانات.

## التحميل

افتح [Releases](https://github.com/mamdouh7809-code/premium-tv-launcher/releases) بعد نجاح البناء، وحمّل:

- **Premium-TV-Launcher.apk**: نسخة محسّنة بـR8 وغير قابلة للتصحيح، موقعة بشهادة اختبار للتثبيت الشخصي.
- **Premium-TV-Launcher-Complete.zip**: مشروع Android Studio كامل ومعه APK، Gradle Wrapper، دليل التثبيت ونتائج البناء.
- ملفات SHA-256 للتحقق من التنزيل.

تظهر حالة البناء والاختبارات في [Actions](https://github.com/mamdouh7809-code/premium-tv-launcher/actions).
لا يعني وجود مصدر المشروع أن APK أو الاختبارات نجحت؛ المرجع هو تشغيل Actions المرتبط بنفس البناء.

## الوظائف

- اكتشاف التطبيقات القابلة للفتح من واجهتي Android TV وAndroid العادية، مع تفضيل نشاط TV.
- فتح التطبيق فعليًا، وعرض أيقونته واسمه من PackageManager.
- مفضلة محفوظة، إخفاء واستعادة، وترتيب مستقل للمفضلة والتطبيقات.
- بحث ولوحة حروف عربية وإنجليزية تعمل بالريموت، مع دعم لوحة المفاتيح الخارجية.
- العربية والإنجليزية ولغة الجهاز، مع عكس اتجاه التنقل في RTL.
- ساعة وتاريخ ومؤشر Wi-Fi أو Ethernet أو VPN، مع التمييز بين الاتصال المحلي والإنترنت المؤكد من النظام.
- أربع درجات لون، وثلاث خلفيات ثابتة، وصورة يختارها المستخدم عبر منتقي النظام.
- هوامش شاشة قابلة للتغيير، وحركة تركيز قصيرة قابلة للإيقاف.
- استقبال تغييرات تثبيت/حذف/تعطيل التطبيقات أثناء عرض الشاشة، وإعادة الفحص عند الرجوع إليها.
- اختيار HOME من النظام عبر RoleManager حيث يتوفر، أو فتح إعدادات الواجهة الافتراضية.

التطبيقات التي لا تحتوي نشاط Launcher لا يمكن فتحها كبطاقات تطبيقات؛ حزم النظام والخدمات ليست تطبيقات مستقلة قابلة للفتح.
الإخفاء ينظّم الشاشة فقط ولا يمنع الوصول إلى التطبيق من إعدادات Android.

## الريموت

| الزر | الوظيفة |
| --- | --- |
| الأسهم | تنقل واضح؛ لا التفاف غير متوقع عند طرف الصف |
| OK / Enter | فتح التطبيق أو تنفيذ الخيار |
| OK مطولًا / MENU | المفضلة، الترتيب، الإخفاء، معلومات التطبيق |
| الأسهم أثناء الترتيب | نقل التطبيق داخل القسم |
| OK أثناء الترتيب | حفظ |
| BACK أثناء الترتيب | إلغاء التغييرات |
| BACK في البحث | إلغاء البحث |
| BACK في الرئيسية | الانتقال لشريط التحكم أعلى الشاشة |
| HOME | فتح الواجهة التي اختارها نظام Android |

## التوافق

المواصفات المنشورة لـX96Q Pro تذكر Android 10، لكن اسم الجهاز وحده لا يثبت إصدار النسخة الموجودة لديك.
افتح إعدادات الجهاز ← حول الجهاز للتحقق قبل التثبيت. ويعرض التطبيق Android وAPI والذاكرة الفعلية في تخصيص ← الجهاز والتوافق.

- الحد الأدنى المحافظ: Android 6.0 / API 23؛ لا توجد مكتبات تتطلب Android أحدث في وقت التشغيل.
- compileSdk/targetSdk: 35. جميع استدعاءات APIs الأحدث محاطة بفحص SDK.
- المعالج: لا توجد مكتبات NDK أو تقييد ABI؛ يدعم ARM 32/64 bit وx86 للمحاكاة.
- التخطيط يتكيف مع مساحة العرض وكثافة dp في 720p و1080p و4K، مع هوامش للشاشات التي تقص الأطراف.
- اختيار 4K لا يعني قياس أداء حقيقي على GPU الجهاز؛ اختبار الأداء والقص على جهازك مطلوب.
- بعض الأنظمة تمنع استبدال HOME. لا روت ولا تعطيل لواجهة الشركة ولا ادعاء بتجاوز ذلك.

## البناء محليًا

المتطلبات: JDK 17، Android SDK Platform 35 وBuild Tools 35.0.0، واتصال لتنزيل اعتماديات Gradle أول مرة.
افتح جذر المشروع في Android Studio واضبط Gradle JDK على 17.

يضيف أول تشغيل ناجح في Actions ملف Gradle Wrapper الرسمي إلى المستودع ويتحقق منه.
إذا حمّلت المصدر قبل ذلك وكان JAR مفقودًا، شغّل أحد سكربتات bootstrap المرفقة، مع فحص SHA-256 الرسمي.

Windows:

~~~powershell
powershell -ExecutionPolicy Bypass -File scripts/bootstrap-wrapper.ps1
.\gradlew.bat :app:lintDebug :app:testDebugUnitTest :app:assemblePreview
~~~

Linux/macOS:

~~~sh
sh scripts/bootstrap-wrapper.sh
./gradlew :app:lintDebug :app:testDebugUnitTest :app:assemblePreview
~~~

مسار APK: app/build/outputs/apk/preview/app-preview.apk.
لبناء نسخة للنشر بشهادتك الخاصة، استخدم Generate Signed Bundle / APK واختر release.
لا تضع مفتاح التوقيع الخاص في هذا المستودع العام.
شهادة الاختبار في CI قد تتغير بين عمليات البناء؛ التحديث فوق نسخة قديمة يحتاج الشهادة نفسها، وإلا يلزم إزالة النسخة السابقة أولًا مما يمسح إعداداتها.
